# Kalkulator BMI (Body Mass Index)
## Deskripsi Project
Kalkulator BMI merupakan aplikasi desktop berbasis Java yang digunakan untuk menghitung Body Mass Index (BMI) atau Indeks Massa Tubuh berdasarkan berat badan dan tinggi badan pengguna. Aplikasi ini dikembangkan menggunakan JavaFX sebagai antarmuka grafis (GUI) dan menerapkan konsep Object-Oriented Programming (OOP), seperti Encapsulation, Inheritance, dan Polymorphism. Aplikasi ini juga menyediakan kategori BMI serta saran sederhana berdasarkan hasil perhitungan.
#
## Tujuan Project
Mempermudah pengguna dalam menghitung indeks massa tubuh.

Mengetahui kategori berat badan berdasarkan nilai BMI.

Memberikan saran sederhana berdasarkan hasil perhitungan.

Menerapkan konsep OOP dalam pengembangan aplikasi Java.

Mempelajari pembuatan aplikasi desktop menggunakan JavaFX.
#
## Fitur Aplikasi
Memilih jenis kelamin pengguna.

Memasukkan berat badan dalam satuan kilogram (kg).

Memasukkan tinggi badan dalam satuan sentimeter (cm).

Menghitung nilai BMI secara otomatis.

Menampilkan kategori BMI.

Menampilkan saran berdasarkan kategori BMI.

Menyediakan tombol reset untuk menghapus input dan hasil perhitungan.
